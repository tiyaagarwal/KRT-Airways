# ✈️ KRT Airways

**KRT Airways** is a fully functional airline ticket booking system built using HTML, CSS, and JavaScript.
This project simulates the complete flight booking process—from login to seat selection and payment.

---

## 🚀 Features

* 🔐 User Authentication (Login & Signup)
* 🏠 Home page with route selection
* ✈️ Flight search between cities
* 👨‍👩‍👧 Passenger details input
* 💺 Seat selection system
* 💳 Payment page simulation
* ✅ Booking confirmation page
* 💾 Uses Local Storage for data handling

---

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling & layout
* **JavaScript (Vanilla JS)** – Logic & interactivity

## ⚙️ How to Run the Project

1. Clone the repository:

```
git clone https://github.com/tiyaagarwal/KRT-Airways.git
```

2. Open the project folder

3. Run the project:

* Open `index.html` in your browser

---

## 💡 Workflow of the System

1. User signs up / logs in
2. Selects source and destination
3. Searches available flights
4. Enters passenger details
5. Chooses seats
6. Makes payment
7. Receives booking confirmation
